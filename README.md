# Fretshift — versões

Instaladores do **Fretshift**, jogo de ritmo que gera as músicas automaticamente a partir de um mp3.
O código do jogo fica num repositório privado; aqui ficam só as versões publicadas.

## Instalar

1. Em [Releases](https://github.com/LCavarcan/fretshift-releases/releases/latest), baixe
   `Fretshift-Setup-<versão>.exe`.
2. Abra o instalador. Como o app não tem certificado de assinatura, o Windows mostra
   "O Windows protegeu o computador": clique em **Mais informações** e depois em **Executar assim mesmo**.

Depois de instalado, o Fretshift procura versões novas sozinho e mostra **Reiniciar para atualizar**
quando uma terminar de baixar.
